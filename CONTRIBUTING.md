## Asking questions

For asking questions, please make sure to use [**Discussions**](https://github.com/karmakrafts/karma-conventions/discussions) instead of **Issues**.

## Styleguides

### Code

- Use the supplied IDEA formatter configuration
- Use the supplied IDEA copyright template 

### Commit messages

- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less
- Reference issues and pull requests liberally after the first line
